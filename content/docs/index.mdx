这是模板自带的示例内容。换成自己的文档时，替换 `content/docs/` 下的页面，或在构建前设置内容仓库，让 `scripts/fetch-content.mjs` 从 GitHub 拉取。

站点负责渲染：侧边栏、站内搜索、Markdown 原文、`llms.txt` 与 OG 图都由框架提供；内容只写 Markdown 与 frontmatter。

| 能力 | 说明 |
| --- | --- |
| 侧边栏 | 目录结构与顺序来自各级 `meta.json`，`---分组名---` 是分隔线 |
| 搜索 | `/api/search`，索引在构建时生成 |
| Markdown 原文 | 任意页面地址后加 `.md`，或带 `Accept: text/markdown` |
| Agent 入口 | `/llms.txt` 索引、`/llms-full.txt` 全文 |
| OG 图 | `/og/docs/<页面路径>/image.png` |

## 下一步

- 改站点名称与语言：编辑根目录的 `site.config.ts`。
- 写页面：见[写第一篇文档](/docs/guide)。
- 内容单独成仓：见仓库 README 的「内容来源」。
